# Start here

Before exploring code, running project commands or preparing changes, read [CONTRIBUTING.md](CONTRIBUTING.md) in full, then the issue and any scoped repository instructions. It is the contribution-policy source of truth; this file is only an entrypoint.

If the policy or required references are unavailable, stop and report the missing input. Follow its assignment, evidence, draft-PR and review gates. Do not infer permission to implement from an unassigned issue.

This repository holds organization-wide policies and templates. Keep policy in the canonical files and link to it from entrypoints. Check Markdown links, template syntax and consistency when changing them. Per-repository rollout is described in [README.md](README.md#rollout); these agent files are not inherited by other clones.
